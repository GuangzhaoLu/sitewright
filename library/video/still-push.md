## vid.still-push

## English

**Slow push on a still.** Problem: There is no footage, so a long generated video is forced to keep deforming.

**When:** You need a little time to unfold, and the material is one still that is already final.

**When not:** The still plus one HTML sentence is already enough. If the motion can make someone unwell and cannot be turned off, do not ship it.

**Steps:**

1. Use a still that has passed grading. Scale or pan slowly, 3–6 seconds.
2. Start and end both sit inside the subject's safe area (see `img.safe-crop`).
3. Text beside it says what this shot means. The motion does not carry the thing to learn.
4. If a CSS transform can do it, do not export a video file (`vid.css-motion-instead`).

**Don't:** A generated stretch where the paper texture and the subject change on every frame, sold as "flowing ink."

**Example:** Sitewright has not used this yet. Take the slow push. Do not take the habit of a documentary voiceover.

## 中文

**静帧缓推.** 问题：没有实拍，却用生成长视频硬做连续变形。

**何时用:** 需要一点时间展开，素材只是一张已定稿的静帧。

**何时不用:** 静帧加一句 HTML 已经够。运动会诱发不适、又不能关掉时，不要上。

**步骤:**

1. 用已过评级的静帧，缓慢缩放或平移，3–6 秒。
2. 起点和终点都落在主体的安全区内（见 `img.safe-crop`）。
3. 旁边文字说完这一镜的信息。运动不承载知识点。
4. 能用 CSS 变换就不要导出成片（`vid.css-motion-instead`）。

**反例:** 生成一段纸纹和主体每帧都在变的「水墨流动」。

**实例:** Sitewright 尚未用过。只取慢推，不取纪录片旁白习惯。

# Video

## English

Default: if it does not need to move, do not make a video. On a learning site, attention belongs on tapping and reading. Video is expensive, hard to caption, and hard on a narrow screen.

Suggested search words: loop, silent, storyboard, Lottie, captions, poster, CSS motion, screen recording, one idea per shot, slow push, stepped stills, compression, reduced motion, seam, transcript, end card, three beats, safe frame, voice, frame by frame.

List the cards:

```bash
python3 scripts/match.py --guild video --list
```

## vid.css-motion-instead

## English

**CSS motion instead of a file.** Problem: A tray falling in, a panel opening, a state change: use a class and a short transition. It can pause, it can respect accessibility, and it does not block a tap.

**Don't:** A 12MB file for a 200ms fall.

**Example:** One state change is a DOM class, not a cutscene.

---

## 中文

**CSS/JS 动效代替片.** 问题：托盘落入、面板展开、状态切换：用 class + 短 transition。可暂停、可无障碍、不挡点按。

**反例:** 用 12MB 的片表现一次 200ms 的落入。

**实例:** 一次状态变化用 DOM class，不用过场片。

## img.limited-palette

## English

**Limited palette.** Problem: Each image brings its own colors, and the hub looks like five sites.

**When:** A new image has to belong to a site that already exists.

**When not:** A photograph is unified by one light source, not by filling the same hex values.

**Steps:**

1. Take five to seven colors from the live site: paper, ink, one accent, one warning. Write them into the style frame.
2. New images use only these hues. Value may change. Hue does not gain a new one.
3. The accent is only for warnings, fiction, and traps, not for decorative glow.
4. If a generated image leaves the palette, generate again. Do not pull it back with a filter.

**Don't:** A new neon key color for every chapter.

**Example:** Sitewright has not made this a project of its own. Use the same colors as `img.style-frame-first`. Do not change the key color every chapter.

## 中文

**限色.** 问题：每张图一套颜色，枢纽看起来像五个站。

**何时用:** 新图要跟已有站。

**何时不用:** 实拍靠统一光源，不靠填同一套色值。

**步骤:**

1. 从现站取 5–7 个色：纸、墨、一个强调、一个警告。写进风格帧。
2. 新图只用这些色相，深浅可以变，色相不新增。
3. 强调色只给警告、虚构、陷阱，不给装饰辉光。
4. 生成图若偏出盘，重抽，不靠后期滤镜拉回。

**反例:** 每章一种霓虹主色。

**实例:** Sitewright 尚未单独立项。和 `img.style-frame-first` 用同一套色，不要每章换一种主色。

## img.reference-board

## English

**Reference board.** Problem: The style frame has no shared reference, and review becomes each person saying what they find handsome.

**When:** There is no frozen style frame yet, and a new round of images is about to start.

**When not:** The style frame is frozen, and you are only adding one image in the same composition.

**Steps:**

1. Collect six to nine images: at least one each for material, camera distance, empty space, and a forbidden example.
2. Include only what you shot, what is already on the site, or what is marked as a reference you may not copy. An image from the web with no provenance does not enter the repo.
3. Write five lines of constraints beside the board, then make the style frame.
4. The reference board does not go on the public page.

**Don't:** Thirty "handsome" images pasted together, with no forbidden example.

**Example:** Sitewright has not used this yet. Do it before steps 1–2 of `img.style-frame-first`.

## 中文

**参考板.** 问题：风格帧没有共同参照，评审各说各的好看。

**何时用:** 还没有冻结的风格帧，要开新一轮图。

**何时不用:** 风格帧已冻，只是按同一构图补一张。

**步骤:**

1. 收 6–9 张：材质、镜头远近、留白、禁止例各至少一张。
2. 只收自己拍的、站内已有的、或注明可参考不可临摹的。来路不明的网图不进仓库。
3. 板旁写 5 行约束，再出风格帧。
4. 参考板不进线上页面。

**反例:** 三十张「好看」混贴，没有禁止例。

**实例:** Sitewright 尚未用过。做在 `img.style-frame-first` 的第 1–2 步之前。

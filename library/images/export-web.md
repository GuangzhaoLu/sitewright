## img.export-web

## English

**Export for the web.**

- Cover as JPG or WebP. Use PNG when you need transparency, and avoid it when you do not
- Hub cards share one aspect ratio, so a row does not jump in height
- Stable filenames. The HTML path is written in place
- Do not commit a 4K original to git

---

## 中文

**上网导出.**

- 封面 JPG/WebP；需要透明用 PNG 但能免则免
- 枢纽卡同一比例，避免一行高低不齐
- 文件名稳定，HTML 写死路径
- 不要 4K 原图进 git

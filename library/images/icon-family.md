## img.icon-family

## English

**One icon family.** Problem: Navigation icons and progress icons are each drawn in their own style.

**When:** You need a set of small icons (layers, progress, exits).

**When not:** Each image is an independent illustrated cover.

**Steps:**

1. One stroke width, one corner radius, one viewBox (for example 24).
2. Use `currentColor` so they follow the theme. No words inside an icon.
3. Align to the grid. One object per icon.
4. Symbols and faces the brief forbids are forbidden in icons too.

**Don't:** One icon each from three free sets.

**Example:** Sitewright has not used this yet. An icon is interface, not a chapter head. Keep it apart from atmosphere JPGs.

## 中文

**图标一族.** 问题：导航和进度图标各画各的。

**何时用:** 需要一组小图标（层、进度、出口）。

**何时不用:** 每张是独立插画封面。

**步骤:**

1. 同一线宽、同一圆角、同一 viewBox（例如 24）。
2. 用 `currentColor`，好跟主题。图标里不写字。
3. 网格对齐。一个图标一个物件。
4. 简报禁止的符号和人脸，图标里同样禁止。

**反例:** 从三套免费图标里各挑一个。

**实例:** Sitewright 尚未用过。图标是界面，不是章头。和氛围 JPG 分开。

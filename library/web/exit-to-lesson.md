## web.exit-to-lesson

## English

**Exit to a real page.** Problem: A link on the main path must open a page or anchor that exists now. If a query parameter opens a panel, also scroll to that entry. An empty "in progress" is not done.

---

## 中文

**出口进真页面.** 问题：主路径的链接必须是现网能打开的页或锚点。用查询参数打开面板时，还要滚到对应条目。空「撰写中」不算完成。

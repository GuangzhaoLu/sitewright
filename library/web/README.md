# Web engineering

## English

Default for a small site: static when it can be static. Progress lives in the browser. Agents run in parallel. They do not nest.

How to arrange a page is in [frontend](../frontend/README.md). Whether to add a database is in [data](../data/README.md). This guild is the engineering contract, not a visual plan.

List the cards:

```bash
python3 scripts/match.py --guild web --list
```

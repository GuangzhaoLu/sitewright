## web.static-html-first

## English

**Static first.** Problem: No bundler, no accounts, no cloud save, unless the brief changes the stack. Python `http.server` is enough to preview.

**Don't:** A full SPA framework for a handful of small rounds.

---

## 中文

**静态优先.** 问题：无打包器、无账号、无云存档，除非简报改栈。Python `http.server` 即可预览。

**反例:** 为四局小游戏上完整 SPA 框架。

## game.filter-layers

## English

**Toggle layers.** Problem: Every material is piled on the table. You cannot see what remains when one kind is taken away.

**When:** Two to four switches. Turning one off or on changes the judgment the player has to make.

**When not:** The layer is only a visual filter and does not affect right or wrong.

**Steps:**

1. Each layer is a switch button, with a note of what the layer is (record / retelling / fiction).
2. Let the player see everything on, then ask them to turn off the layer the brief names, and answer "does it still stand?"
3. Layer state uses words, not opacity alone.
4. `mark` only when the answer is right in the layer state the spec names.

**Don't:** Four switches flipped at random, and the last question ignores the layers.

**Example:** Sitewright has not used this yet. Unlike `sort-trays`: trays carry cards away, and this card is switches on the same pile.

## 中文

**叠层筛选.** 问题：材料全堆在桌上，看不出拿掉某一类会剩下什么。

**何时用:** 2–4 个开关，关掉或打开之后，玩家要做的判断会变。

**何时不用:** 层只是视觉滤镜，不影响对错。

**步骤:**

1. 每层一个开关按钮，旁注这层是什么（记录 / 转述 / 文艺）。
2. 先让玩家看全开，再要求关掉简报指定的层，然后回答「还站得住吗」。
3. 层的状态用文字，不只靠透明度。
4. 在指定层状态下答对才 `mark`。

**反例:** 四个开关随便拨，最后一题不看层。

**实例:** Sitewright 尚未用过。与 `sort-trays` 不同：托盘是把卡片分走，这里是同一堆上开关。

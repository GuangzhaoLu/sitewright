## game.margin-label

## English

**Label the margin.** Problem: The main text, the commentary, and a later elaboration are printed as one paragraph.

**When:** One short passage has at most six sentences, and each sentence must be labeled with a role the brief defines (text / note / elaboration).

**When not:** The materials are already separate cards — use `sort-trays`. If you are grading how citable a source is, use `source-grade`.

**Steps:**

1. Each sentence is a button. Tap the sentence, then tap the role.
2. A wrong label: say whether this sentence explains the previous one or starts something else.
3. At most three roles.
4. `mark` only when every label is right.

**Don't:** Type size is the only clue, so the player does not have to read.

**Example:** Sitewright has not used this yet. Unlike trays: the sentences are still inside the paragraph and cannot be physically separated first.

## 中文

**边注归类.** 问题：正文、注文、后人发挥印在同一段里。

**何时用:** 同一短段里有 ≤6 句，每句要标成简报规定的角色（正文 / 注 / 发挥）。

**何时不用:** 材料是分开的卡片——用 `sort-trays`。要评引用等级——用 `source-grade`。

**步骤:**

1. 每句一个按钮，点句再点角色。
2. 标错：说明这句是在解释上一句，还是另起一事。
3. 角色 ≤3。
4. 全部标对才 `mark`。

**反例:** 用字体大小当唯一线索，玩家不用读。

**实例:** Sitewright 尚未用过。与托盘的差别是句子还嵌在段里，不能先物理分开。

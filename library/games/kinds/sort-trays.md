## game.sort-trays

## English

**Sort trays.** Problem: The materials differ in reliability, but the reader sees them laid out as one glance.

**When:** The learning job is sorting or classifying, and it has to be done by hand.

**When not:** There are only two piles, right and wrong, and the labels are already written on them.

**Steps:**

1. At most three trays. Each tray has one sentence of criterion (for example: record / retelling / story).
2. One card at a time. Tap the card, then tap the tray (do not rely on drag alone).
3. A right placement: it falls in, with a short explanation. A wrong one: a light shake, plain words, and one line of narration.
4. Lock this question before "next." Focus returns to the first choice of the next question, so Enter cannot skip ahead to a win.
5. `mark` only when all are correct.

**Don't:** Trays as decoration, so the sort does not affect winning or losing. Color as the only layer.

**Example:** The lowest tier must say it cannot be used as evidence. Do not put one row's proper name into a tray's name.

## 中文

**分层托盘.** 问题：材料可靠度不同，读者却平铺在同一眼。

**何时用:** 教学目标是「分层 / 分类」，必须动手。

**何时不用:** 只有对错两堆且标签已经写在脸上。

**步骤:**

1. 3 个以内托盘，每盘一句分类标准（例如：记录 / 转述 / 故事）。
2. 卡片一次一张。点卡片再点托盘（不要只靠拖）。
3. 放对：落入并短解释。放错：轻震 + 白话 + 一句旁白。
4. 必须本题锁住才给「下一题」。焦点回到下一题第一个选项，避免回车跳题通关。
5. 全部正确才 `mark`。

**反例:** 托盘当装饰、分类不影响输赢；用颜色当唯一分层。

**实例:** 最低一档要写明不能当作证据。不要把某一行的专名写进托盘名。

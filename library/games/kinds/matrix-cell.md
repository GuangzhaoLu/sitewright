## game.matrix-cell

## English

**Two-axis grid.** Problem: Two dimensions are mashed into one label.

**When:** Two axes, two or three stops each. Objects go into cells, and the cells do not mean the same thing.

**When not:** Only one dimension — use `sort-trays` or `continuum`.

**Steps:**

1. Axis names are in the headers. Cells use short labels, not color alone.
2. Tap the object, then tap the cell. A miss: say which axis it missed.
3. If there are too many cells, delete an axis. Do not build a 5×5.
4. `mark` only when every object is in the cell the spec names.

**Don't:** The two axes are two wordings of the same thing.

**Example:** Sitewright has not used this yet. The axes are written in the project brief (for example genre × how citable), not frozen into this card.

## 中文

**双轴入格.** 问题：两个维度被揉成一个标签。

**何时用:** 两个轴各 2–3 档，物件要放进格子，且格子含义互不重复。

**何时不用:** 只有一个维度——用 `sort-trays` 或 `continuum`。

**步骤:**

1. 轴的名字写在表头。格子里用短标签，不只用颜色。
2. 点物件再点格子。放错：说它在哪一轴上偏了。
3. 格子多了就删轴，不要做 5×5。
4. 全部入规格格才 `mark`。

**反例:** 两轴其实是同一件事的两种说法。

**实例:** Sitewright 尚未用过。轴写在项目简报（例如体裁 × 可引用程度），不写死在本卡。

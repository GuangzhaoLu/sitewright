## game.stack-build

## English

**Stack in order.** Problem: A structure has a bottom and a top, and a bullet list does not show what collapses.

**When:** Three to five blocks. The brief names the only stable order, or the only block that can take the load.
**When not:** Any order is fine, or you are teaching a timeline with no "under" and "over" (`game.sequence-order`).

**Steps:**

1. Show a base. Blocks are buttons. Tap a block to place it on the current top.
2. If the block cannot sit there, it does not stay, and one sentence says what has to be under it.
3. Undo is a button, one block at a time.
4. `mark` when the stack matches the spec. No drag-only tower, no physics toy without a target.

**Don't:** A score for height. Do not let a wrong stack quietly stand.

**Example:** A wall, a meal, a layer cake of materials. Block ids and the legal order are in JSON.

## 中文

**按层搭起来.** 问题：结构有底有顶。项目符号看不出什么会塌。

**何时用:** 三到五块。简报写明唯一站得住的顺序，或唯一承得住的那一块。
**何时不用:** 什么顺序都可以，或只是没有上下关系的时间线（用 `game.sequence-order`）。

**步骤:**

1. 先给出底座。块是按钮。点一块，它就放到当前的顶上。
2. 若这块不能放在那里，它不留下，并用一句话说下面必须先有什么。
3. 「撤回」是按钮，一次拿掉一块。
4. 堆叠符合规格才 `mark`。不要只能拖的塔，也不要没有目标的物理玩具。

**反例:** 按高度记分。不要让错误的一摞悄悄立着。

**实例:** 一堵墙、一餐、一层层材料。块的 id 和合法顺序写在 JSON 里。

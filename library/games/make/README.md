# Make

## English

How a matched kind becomes a round someone will finish. These are not extra game types.

Use them with a kind:

- One verb, obvious on the first line
- A response in words, in the same view
- A miss that teaches and can be tried again
- A small confirmation, not a carnival
- A done state and a link to the next real page
- One page or one section, content in JSON

```bash
python3 scripts/match.py --guild games "好玩 页面 反馈"
```

---

## 中文

匹配到的种类，怎样变成一局有人会做完的东西。这些不是新的游戏类型。

和种类一起用：

- 一个动作，第一行就看得懂
- 同一屏里用文字回应
- 点错仍在教，并且可以再试
- 轻一点的确认，不是庙会
- 做完的状态，以及到下一张真页面的链接
- 一页或一节，内容在 JSON 里

```bash
python3 scripts/match.py --guild games "好玩 页面 反馈"
```

## fe.page-job

## English

**One job per page.** Problem: The home page tries to be a catalog, an advertisement, and the whole product at once.

**When:** Any new page.

**When not:** A poster with one primary action and no second job.

**Steps:**

1. Write one sentence for what this page asks a person to finish. If you cannot, split the page.
2. One primary button. Other exits become text links.
3. The page title and that sentence use the same wording. Do not add a separate marketing slogan.
4. A feature the brief did not name does not appear on this page.

**Don't:** Five primary buttons of the same size, so the reader does not know which to press first.

**Example:** Sitewright has not used this on its own yet. A news graphic starts by stating what question the page answers.

## 中文

**一页一事.** 问题：首页同时想当目录、广告和全部功能。

**何时用:** 任何新页面。

**何时不用:** 一张海报、一个主动作，没有第二条任务。

**步骤:**

1. 用一句话写下这一页让人完成的事。写不出就拆页。
2. 一个主按钮。其余去路降成文字链。
3. 页题和这句话用同一种说法，不要另起营销口号。
4. 简报没写的功能不出现在这一页。

**反例:** 五个同样大的主按钮，读者不知道先点哪个。

**实例:** Sitewright 尚未用过。新闻图形稿先澄清「这一页回答什么」。

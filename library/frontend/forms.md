## fe.forms

## English

**Ask little in a form.** Problem: The page asks for a long list of facts before it has given anything.

**When:** The brief includes a form or an input.

**When not:** There is no user input. Do not add registration to feel complete.

**Steps:**

1. Ask only for the fields the brief names. Each field has a visible label, not only a placeholder.
2. Errors sit beside the field, in words. After a correction, fields that were already right stay filled.
3. Submit is a button. Block double submits while it is in flight, and allow another try if it fails.
4. Accounts, captchas, and payments do not appear unless the brief includes them.

**Don't:** Twelve fields before someone can read an article.

**Example:** Sitewright defaults to no accounts. To remember progress on this device only, use local storage. Do not build a signup table.

## 中文

**表单少问.** 问题：还没给人价值，先要一长串资料。

**何时用:** 简报里有表单或输入。

**何时不用:** 没有用户输入。不要为了「完整」加注册。

**步骤:**

1. 只问简报写明需要的字段。每字段有可见标签，不只靠占位符。
2. 错误写在字段旁，用文字。改完不必重填已经对的项。
3. 提交是按钮。提交中防止连点，但失败要能再试。
4. 账号、验证码、支付不在简报里就不要出现。

**反例:** 读一篇文章要先填十二项。

**实例:** Sitewright 默认无账号。只在这一台设备上记住进度时，用本地存储，不建注册表。

## fe.type-measure

## English

**Type size and measure.** Problem: Body text is small and gray, and a line is so long the eye cannot find the way back.

**When:** A page someone is meant to read through.

**When not:** A page that is only a one-word button.

**Steps:**

1. Body text is at least `1rem`. Input text is at least `16px`, so a phone does not zoom the whole page on focus.
2. Wrap at about 60–75 characters (about 30–40 Chinese characters). Do not stretch a line across a wide screen.
3. Line height makes the start of the next line findable. Contrast is readable. Thin gray type is not a style.
4. Words that must be read live in HTML, not painted into an image (see `img.type-stays-html`).

**Don't:** A 12px gray article in one full-width line.

**Example:** Sitewright has not used this yet.

## 中文

**字号与行长.** 问题：正文又小又灰，一行长到读不回来。

**何时用:** 要人读完的页。

**何时不用:** 只有一个词的按钮页。

**步骤:**

1. 正文不小于 `1rem`。输入框字体不小于 `16px`，避免手机聚焦时整页被放大。
2. 行长大约 60–75 个字（中文约 30–40 字）就换行，不要通栏拉满宽屏。
3. 行距让下一行的起点找得到。对比度够读，不靠细灰字当「高级」。
4. 必须读的字放在 HTML 里，不画进图（见 `img.type-stays-html`）。

**反例:** 12px 灰色通栏长文。

**实例:** Sitewright 尚未用过。

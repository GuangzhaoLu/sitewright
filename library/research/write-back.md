## res.write-back

## English

**Write the method back.** Problem: A new card has an id, tags, when / when_not, steps, and a counterexample. Create one file in that guild's directory and register it in `catalog.json`. The guild README is not a third index. List cards with `match.py --guild … --list`. The example may name a project. Do not put copyrighted images in the Sitewright repo. Do not rename an id prefix to the full directory name.

---

## 中文

**写回.** 问题：新卡片：id、tags、when / when_not、步骤、反例。在对应行当目录新建一个文件，并登记 `catalog.json`。行当 README 不是第三份索引，名单用 `match.py --guild … --list`。实例栏可写项目名。不要把版权图放进 Sitewright 仓库。不要把 id 前缀改成目录全名。

# 硬教训

付过学费的，不要再学一遍。

1. **规格是唯一规则。** 提示词是规格的副本。口头改规则不算数。
2. **一局一个观念。** 花活第二，教什么第一。错要教，不要羞辱。
3. **点按优先。** 热区大约 44px。拖拽不能当唯一过关方式。
4. **一套安静色盘。** 强调色给警告 / 虚构 / 陷阱，不给镀铬。
5. **无账号、无惩罚计时、无抽奖箱。** 除非简报写明要做产品账号。
6. **领域陷阱写在项目简报。** 例如「某句流行话不得当作正确答案」。通用提示词里不写死领域专名。
7. **实现席位从指挥平行发出。** 禁止 Task 里再 Task 并等待。
8. **先 `match.py` 再发明。** 游戏、图、视频都一样。
9. **通关只 `mark` 一次、只在真条件。** 跳题、焦点留在「下一题」、选中陷阱项，都不得写进度。
10. **冷却才写回库。** 做的时候不要边做边改 Sitewright 目录的规格；做完把可复用的卡片补上。

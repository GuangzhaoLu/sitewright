# Basecamp Shape Up · 塑形、下注、建造、冷却

公开来源：[Shape Up](https://basecamp.com/shapeup/)（Ryan Singer）。循环常见说法是约六周建造 + 约两周冷却；Sitewright 只借**结构**，不借日历。

## 他们实际在做什么

1. **塑形 Shaping**：高级的人把问题收窄、给出解决方案的轮廓、定**胃口**（愿意花多少时间），颗粒度是「油性笔」——太细会变成规格八股，太粗团队会迷路。
2. **下注 Betting**：在冷却期的赌桌上选下一轮做哪几个 pitch。没有无限 backlog。不赌的就让它掉下去。
3. **建造 Building**：小队在胃口内自己切块。到点做不完，默认**熔断**，回去重新塑形，而不是「再给两周」。
4. **冷却 Cool-down**：修小东西、写文档、想下一轮，不立刻填满新功能。

## 网页小站能用的

| 拿走 | Sitewright 里的落点 |
|---|---|
| 塑形 | S1：匹配工艺库 + 写简报轮廓 |
| 胃口 | 一轮能玩通；不加第五局 |
| 下注 | S2：用户确认后才开发现波 |
| 油性笔 | `01-GAMES` 写循环和陷阱，不写像素 |
| 熔断 | 做不完就交付已通的，P2 进冷却 |
| 冷却写文档 | S7：卡片写回 `library/` |
| 不养无限待办 | P2 列在 QA 报告，下一轮重新下注 |

## 不要用的

- 机械执行「必须六周」。
- 把冷却变成偷偷做下一轮大功能。

## 刻意没搬进来的

- 微服务与独立发布（小队自主部署）——静态小站用不上，硬搬会拆碎一个 HTML 目录。
- 每周用户访谈配额——没有真实用户研究管道时，用冻结简报 + 验收清单代替，不要假装有研究。
- 六周日历——agent 一轮以「能玩通」为胃口，不按工时打卡。

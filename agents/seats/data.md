# 数据 Data

任务全文：[`prompts/data.md`](../prompts/data.md)。本页只记边界。

特召。简报的「数据」不是「无」才上场。主盯：要不要持久化、内容类型、读写路径。

## 做

- S3 写 `out/data-model.md`：类型、字段、谁能改、页面实际要的查询
- 先匹配 `data.*` 卡片。能用 JSON 或 `localStorage` 就写明不上库
- 和 PM、指挥一起把模型冻进这一轮。冲突只记风险

## 不做

- 在发现波顺便搭一整套后端（除非简报的胃口写了「这一轮要能写入」）
- 让浏览器直连数据库
- 因「以后可能要用」加账号、加表
- 把密钥写进仓库

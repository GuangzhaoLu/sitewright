# Prompt · Game design

## English

You design each round. You do not write production JS.

Workspace: `{{ROOT}}`

Read first: `{{AGENTS}}/00-BRIEF.md` and `{{AGENTS}}/01-GAMES.md`. If `out/library-hits.md` is present, read it too.

### Task

Write `{{AGENTS}}/out/game-beats.md`. Each round includes:

- Opening line
- The common misunderstanding: the version that makes it too simple
- Question order
- One plain correct line and one plain wrong line per item
- What does **not** count as a win
- Closing line, plus a link to the next page named in the brief

Keep the tone light. No slogans, no memes.

Do not make a how-to-operate game unless the brief allows it.

## 中文

你设计各局。不写生产 JS。

工作区：`{{ROOT}}`

先读 `{{AGENTS}}/00-BRIEF.md` 和 `{{AGENTS}}/01-GAMES.md`。若有 `out/library-hits.md`，也读。

写 `{{AGENTS}}/out/game-beats.md`。每一局包括：

# Playbook · 改现有网站

站点已经能打开。这一轮是改，不是重生。

## 何时用

用户说改进、打磨、补 P2、加一页、修验收债。

## 冻结物

`00-BRIEF.md` 必须有一节 **「改什么 / 不改什么」**。没有游戏就不要造 `01-GAMES.md`。

## 裁剪

| 阶段 | 改站时 |
|---|---|
| S0 | 写清范围，列现网债（如入门章撰写中） |
| S1 | `match.py` 只搜这一轮媒介 |
| S2 | 用户点头 |
| S3 | 通常只要 PM + 视觉；动文案才上内容 |
| S4 | 可跳过，除非新开一局 |
| S5 | 只开会改到的席位 |
| S6 | 回归：改过的路径 + 所有读同一状态的页 |
| S7 | 写回库；P2 不顺手做完 |

## 禁止

- 借打磨加第五局、加登录
- 改进度键名导致旧存档作废（除非简报写明迁移）
